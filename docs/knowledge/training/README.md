# 训练方法知识库

更新：2026-09-08。用于练伴的复盘、整次训练推荐及评估设计。

## 阅读入口

1. [Michael Boyle《体育运动中的功能性训练》知识初稿](michael-boyle-functional-training.md)：目前只核读出版社官方节选，未完成全书精读。
2. [研究证据与来源登记](evidence-register.md)：逐项记录研究类型、阅读范围、结论边界及产品影响。
3. [训练决策规范 v1 草案](../../superpowers/specs/2026-09-08-training-decision-v1.md)：复盘和推荐的输入、判断、呈现与验收。
4. [三份训练决策样例](../../superpowers/specs/2026-09-08-training-decision-examples.md)：全部使用合成数据，供讨论输出质量。

## 使用约定

- 作者经验、研究结论和产品规则分别标记，不把来源数量当作证据强度。
- “读取了官方节选/论文摘要”与“阅读全文”分别登记；不补造页码或未读章节结论。
- 每项训练规则必须能追溯到具体来源或明确标注的产品假设，并记录适用目标与人群。
- 数字事实由程序计算；模型生成的解释不得替代数据校验。缺失记录不等于没有训练。
- 这些文件是设计资料，尚未接入运行时检索或自动执行；当前 chatbot 能力以服务代码为准。
- 取得原书后优先补充方案设计、评估、进阶和完整训练编排的阅读记录，再更新相关规则版本。
- 保存原创概括、出处和适用性判断；不保存整本商业图书的复制件或可替代原书的动作图册。
