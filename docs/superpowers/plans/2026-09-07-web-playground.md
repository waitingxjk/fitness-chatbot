# 练伴 Web 测试界面

目标：浏览器连接现有 FastAPI，持续 NDJSON 对话、观察处理阶段、查看动作卡和历史。
保留既有 Python 项目结构，前端作为包内静态资源；不引入独立前端服务或代理。
布局为左侧会话列表、中央对话、右侧运行检查面板。深蓝侧栏与青绿色状态色，中文界面。

- [x] 增加可持久化 trace 事件：解释完成后的检索条件、结果数量与 ID、回答阶段。
- [x] 编写 NDJSON 分块解析及状态归并测试，验证中文跨字节、未知事件、error/done 和断流。
- [x] 实现同源连接状态与重连、连续聊天、停止、新建会话、历史分页和动作详情。
- [x] 静态资源由 FastAPI /playground/ 提供，跟随 uv run fitness-bot 启动。
- [x] 验证 Python 接口、浏览器流解析逻辑、打包和启动；打开可用预览。

“思维过程”仅指可观测执行信息，不输出模型隐藏思维链。历史使用服务端 MySQL，
浏览器仅保存选中会话 ID，不缓存聊天正文。历史无 trace 时明确说明无运行记录。
新建会话先在浏览器分配 UUID，第一条请求时写入数据库；流进行中阻止切换避免串会话。

联调修复：向回复模型传递上一组完整动作资料，跨无卡片追问保留引用；
隔离 LangGraph 生成任务并等待取消清理，确保 HTTP 断连后保存部分文本、释放会话锁。
