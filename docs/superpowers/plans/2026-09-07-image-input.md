# Web 图片输入

在现有测试台输入框增加选图、缩略图、移除与大图预览，保留 NDJSON 回复协议。
每条消息最多 3 张 JPEG/PNG/WebP，每张最多 5 MiB、20 MP，拒绝损坏和动画图片。
图片先通过同源 POST /v1/images 上传原始文件体，返回本地资源 ID；聊天 JSON 使用 images ID 列表。
图片文件存放 runtime/uploads（Git 忽略），新建 chat_turn_media 表保存消息与图片关联，
不修改已有表结构。历史返回可预览的图片信息，失败轮次也保留关联。

模型计划和回复均使用原生 image_url 内容块。本轮最多 3 张，历史取最近 6 张图片，
较早图片保留在存储及测试页，模型消息明确提示其已省略。纯图片输入可发送，空请求仍拒绝。
上传失败显示错误并允许移除/重试；上传时阻止发送或切换会话；聊天失败恢复图片草稿。

验证：真实文件校验、超限/损坏拒绝、服务重启后图片及历史恢复、模型两阶段图像内容块、
前端选择与上传失败处理、原有文本/流式/停止回归；自动测试不调用付费模型。
